# Testes Vigilante — Segurança Privada (Portugal)

Banco de perguntas e resumos de estudo para o curso/exame de vigilante de segurança privada.

## Conteúdo

- `quiz/index.html` — quiz interativo: teste geral (25 perguntas), todos os módulos ou treino por módulo. Basta abrir no browser.
- `perguntas/testes-vigilante-limpo.csv` — banco de 354 perguntas (Verdadeiro/Falso e resposta direta), limpo e normalizado.
- `estudo/` — resumos de estudo por módulo (15 módulos: ALM 01–02, BAS 01–06, VIG 01–07).

## Quiz interativo

Abre `quiz/index.html` em qualquer browser (telemóvel ou computador, sem internet):
- **Teste geral**: 25 perguntas aleatórias de todos os módulos.
- **Todos os módulos**: 339 perguntas V/F baralhadas.
- **Por módulo**: treinar cada módulo em separado.
- Feedback imediato (correto/errado com explicação) e botão "Seguinte" obrigatório para avançar.

## Estrutura do CSV

```
Módulo,Origem,Tipo,Pergunta,Resposta,Observação
```

- **Origem**: `Criada` (elaborada para estudo) ou `Oficial` (de testes reais).
- **Tipo**: `V/F` (verdadeiro/falso) ou `Normal` (resposta direta).

## Notas

- Módulos normalizados (ex.: `VIG03` → `VIG 03`); duplicados exatos e quase-duplicados removidos; colunas desalinhadas corrigidas.
- Os resumos em `estudo/` seguem o formato: essencial, o que decorar, perguntas típicas, truques para verdadeiro/falso e mini-resumo.
